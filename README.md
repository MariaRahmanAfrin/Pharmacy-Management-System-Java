# 💊 Pharmacy Management System (Java Swing)

A desktop GUI application built using **Java** and **Java Swing** to streamline pharmacy operations, medicine ordering, and billing processes.

---

## ✨ Features
* 🏥 **Medicine Catalog:** Interactive panel to browse available medicines.
* 🛒 **Dynamic Shopping Cart:** Add items, modify quantities, and remove products with real-time price calculation.
* 💳 **Checkout & Billing System:** Collect customer details, choose payment methods, and calculate grand total.
* 🔄 **Modular UI Navigation:** Smooth screen transitions using Java Swing's `CardLayout`.

---

## 🛠️ Tech Stack & Tools
* **Language:** Java (JDK 8+)
* **GUI Framework:** Java Swing & AWT
* **IDE:** NetBeans IDE
